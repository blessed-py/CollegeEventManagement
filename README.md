College Event Management

You are developing a small College Event Management Website. Your work must be maintained using Git and GitHub.
Task:
1. Create a GitHub repository named CollegeEventManagement
2. Clone the repository to your local computer
3. Create an index.html file containing:-
	-College Name
	-Event Name
	-Event date
	-Registration information
4. Add and commit the file with a suitable commit message.
6. Push the changes to the remote GitHub repo.
6. Create a new branch named event registration
7. Switch to the event registration branch and create registration.html containing a simple student registration form.
8. Add, commit, and push the new branch to GitHub.
9. Switch back to the main branch.
10. Make one modification to index.html
11. Commit and push the modification.
12. Merge the event-registration branch into the main branch.
13. Push the final merged changes to GitHub.
14. Display the available branches and commit history.
